# Reporting Security Issues

If you discover a security issue in django-watchman, please report it privately using
GitHub's [private vulnerability reporting](https://github.com/mwarkentin/django-watchman/security/advisories/new).

If you can't use GitHub, you can email
[mwarkentin+django-watchman@hey.com](mailto:mwarkentin+django-watchman@hey.com) instead.

Please don't open a public issue for security problems. Reporting privately allows me
to assess the risk and make a fix available before the issue is disclosed.

Thanks for helping make django-watchman safe for everyone.
